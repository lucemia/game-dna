Generate one style-reference sheet for your game, lock it, and pass it as a reference image to every later generation. The whole set then shares one hand: the same light, outline, palette and proportions. The game only loads the saved files, so every frame stays reproducible.

1 · Lock one reference sheet

One image with a character, a prop, a ground patch and an icon, made from a fixed style paragraph. Its file and sha256 are saved; from now on every prompt carries the same paragraph and this sheet as referenced_image_paths.

Style lock paragraph (identical in every prompt)
modern hand-painted 2D game art for an original top-down adventure game; soft painterly brushwork over clean readable shapes; camera looking down at about 35 degrees; one key light from the top-left, warm lantern-amber highlights against cool blue-green forest shadows; a thin dark warm-brown outline; muted earthy palette: moss green, slate blue, warm amber, cream, walnut brown; contact shadows under feet only; characters about 3.5 heads tall. Original, no resemblance to any existing game, film or franchise character, no text, no logo, no watermark.
Sheet:
The sheet is the art director. Words alone describe a style; the image pins down the exact brushwork, value range and head-to-body ratio the words leave open.

2 · What locking buys, and what it does not

Three ways to prompt the same assets. Words only: a plain one-line prompt per asset, the way most people start. Paragraph only: every prompt ends with the same STYLE LOCK paragraph, no sheet. Locked: the paragraph and the sheet as a reference image. The bars are the mean palette distance of the scene's assets to the matching sheet item (stylestats.py, lower is closer). 3 · Where the sheet matters: new characters next to the existing cast

No seed: each run is a new picture, so assets are saved as files. Below, repeated runs of one prompt, all ending with the STYLE LOCK paragraph, with and without the sheet. Without the sheet the runs still agree with each other (the guards even more than with it: spread 0.010 vs 0.021), but they agree on a look that is further from the keeper already in the game: the guards' palette distance to the keeper doubles (0.205 vs 0.107), and the herbalists come out wider and stooped (width/height 0.634 vs the keeper's 0.567) with twice the run-to-run spread in shape (± 0.039 vs ± 0.018). Not everything improves: lightness is not closer to the keeper with the sheet, and part of the guards' gain is costume colour: the locked guards borrow the keeper's moss-green hooded cape. For one village cast that is acceptable; if a new character must not echo an existing outfit, add "do not reuse the reference character's clothing" to its prompt. So the paragraph keeps a set consistent with itself; the sheet keeps new assets consistent with art you already have.
