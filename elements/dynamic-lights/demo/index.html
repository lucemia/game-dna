Dynamic 2D lights & soft shadows

Point lights and spotlights with soft falloff, colour and flicker; lights that ride on actors (the hero's torch, fireballs) and flash on impacts; walls, pillars and crates cast soft shadows in real time. A light map is composited in a WebGL post pass, so the HUD stays unlit. Without WebGL the plain 2D game shows.
