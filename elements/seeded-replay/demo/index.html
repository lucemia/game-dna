Seeded replay & ghost

Every fixed step the module stores the run's input next to its seed. Played back through the game's own step function, the run reaches the same end state, checked by hashing the state every second and at the finish. Your best run comes back as a translucent courier that races you with a live split. Replays save and load as one line of text.
