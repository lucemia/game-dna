Branching run map

A seeded roguelite route: floors of battle, elite, event, shop and rest nodes join on the way up to a boss, with paths that never cross. Pick the next node with arrows, mouse or touch; the token travels, the game plays that node (here a stand-in fight), and the map comes back one floor higher with your route drawn in gold. Shop, rest and event nodes run as small panels whose choices are the game's own callbacks.
