Modern particle system

One pooled, seeded engine for thousands of smooth particles: emitter shapes (point, line, circle, rect, sprite outline), size, alpha and colour curves over each particle's life, additive glow, gravity, drag, wind and ground bounce. Presets for bursts, fountains, smoke, magic swirls and bouncing sparks; deterministic from a seed and game time.
