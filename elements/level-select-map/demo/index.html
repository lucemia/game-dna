B-05

Level-select path reveal

An overworld map between levels. The hero walks node to node along open paths; clearing a level draws the next path stone by stone while the camera follows; a secret exit opens a different path; locked paths show faint; huts save, shops open; the map scrolls when it is bigger than the screen. The game supplies the graph, the cleared state and what entering a level does.

MapArrows walk, Z enters. Click a node to walk there.
