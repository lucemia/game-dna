B-01

Grid movement range + path arrow

Select a unit to see where it can walk (blue) and what it can hit (red). Move the cursor to draw the cheapest path; confirm to walk it tile by tile.
reachableattack fringepath arrow

Parameters

Keyboard ←↑→↓ or WASD move (hold to accelerate) · Z/Enter select, confirm · X/Esc cancel
Mouse hover to aim, click to select / confirm, right-click to cancel
Touch tap a tile to aim, tap it again to confirm
