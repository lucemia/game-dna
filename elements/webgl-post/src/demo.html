WebGL post-process pipeline

The game keeps drawing on its own 2D canvas. Each frame that canvas becomes a texture on a WebGL layer laid exactly over it, and a chain of shader passes runs at device resolution: a filmic grade with vignette, and a chromatic hit-pulse. Without WebGL the 2D canvas shows exactly as before.

Example pass: depth haze

A 20-line pass added with addPass, reading a depth canvas the scene provides through setInput('depth', canvas): the slot later depth-of-field and light elements use. Like every pass in the family it also reads uiMask, so the HUD is never hazed.
