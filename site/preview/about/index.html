About Game DNA

What it is

A library of game elements for people who make browser games with an AI coding agent. Each element is a demo you can play, a module file that does the hard part, and a prompt that tells your agent how to connect it to a game it has never seen. Elements combine: the basket turns several into one prompt.

How we test the prompts

Before an element goes up, a fresh coding agent gets only a game it has never seen, the module and the prompt, and an independent reviewer plays the result. Each element's demo is also reviewed for how it looks and feels.

Art

All art is original. Most of it is drawn in code. Some demo art (painted scenes, portraits, UI frames, card art, some HD sprites and backgrounds) was made with an AI image generator; the game code, the pixel art drawn in code and the prompts are our own. Elements whose demo shows such pictures are marked ✦ AI art. Each picture was made once, checked against resemblance to existing games, characters or brands, and its prompt and generation record are kept with the project. The modules themselves never call a generator.
