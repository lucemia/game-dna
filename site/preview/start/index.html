Start in 5 minutes

Add your first element

You need a browser game (one HTML file is enough) and a coding agent: Claude Code, Codex, Cursor or similar.

  1. 1

    Pick an element

    Play a few demos and choose one that fits your game. Add-ons go into any game; starter games are complete games to extend. Small add-ons are the easiest first try.

  2. 2

    Copy the prompt

    On the element's page press Copy prompt, and download the module and its README into your game's folder.

  3. 3

    Paste it to your agent

    Open your agent in the game's folder and paste the prompt. Add one line about your game, e.g. "My game is index.html; hits happen in attack()."

4. What to check

  • Play your game: the element shows up where the demo showed it.
  • Your game still plays to the end; nothing else changed.
  • No errors in the browser console.
  • Try a phone-sized window if your game runs on phones.
  • Ask your agent to run the checks at the end of the prompt.

Several at once

Add elements to the basket. It checks that they fit together, puts them in order and writes one prompt plus a zip of the module files. You can also start from a ready-made game or pick an art style.
