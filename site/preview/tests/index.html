How we test

Every element, every run, failures included

1. Visual review

Each demo is reviewed by a separate agent against commercial indie games, character by character and at 2x zoom. It passes at 7.5 out of 10 with no major issue (parts not joined, placeholder art, debug leftovers, unreadable text on phones). Most elements needed several rounds.

2. Runs on unseen games

A fresh coding agent gets only a game it has never seen, the module and the prompt: no browser, no access to this project. A different agent then plays the result. A run passes when the element works, nothing in the game broke, and the game still plays to the end. When a run fails we fix the prompt or the module and run again; the old result stays below.
