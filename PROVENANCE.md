# Art provenance

Most art in Game DNA is drawn in code. Some demo art was made with an AI image generator: OpenAI image generation, used through Codex. The game code, the pixel art drawn in code and the prompts are our own. Pages whose demo shows AI pictures are marked with ✦ AI art. The element modules never call an image generator.
